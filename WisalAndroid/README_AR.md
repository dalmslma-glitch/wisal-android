# مشروع وصال للأندرويد

هذا مشروع Android Studio أصلي بلغة Kotlin وواجهة Jetpack Compose، بتصميم عربي RTL وألوان أزرق ملكي وذهبي.

## الموجود حالياً
- شاشة دردشات بقائمة محادثات تجريبية.
- شاشة محادثة محلية: إرسال الرسائل يضيفها إلى الشاشة فقط.
- تبويبات الحالات والمجموعات وجهات الاتصال والملف الشخصي.
- تصميم عربي قابل للتطوير.

## ما الذي لا يعمل بعد؟
هذه نسخة واجهة أولية وليست خدمة مراسلة متصلة بالإنترنت. لا يوجد حتى الآن:
- تسجيل حسابات ومصادقة.
- خادم وقاعدة بيانات للرسائل.
- مزامنة فورية بين هاتفين.
- رفع صور/ملفات أو تسجيل صوتي.
- إشعارات دفع أو مكالمات.

يلزم ربط Backend (مثل Firebase أو Supabase) وإعداد مفاتيح المشروع وسياسات الخصوصية قبل إطلاق مراسلة حقيقية.

## بناء APK
1. افتح مجلد المشروع في Android Studio حديث.
2. انتظر مزامنة Gradle وتنزيل الاعتماديات.
3. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
4. ملف APK التجريبي يظهر عادةً في `app/build/outputs/apk/debug/app-debug.apk`.
